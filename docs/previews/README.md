# `docs/previews/` — Previsualizaciones HTML

HTMLs que replican a tamaño real el formato de comandas y tickets impresos, útiles para revisar cambios en el layout ESC/POS sin necesidad de imprimir físicamente.

| Archivo | Muestra |
|---|---|
| `comanda-preview.html` | Comanda de cocina — versión anterior con dos secciones |
| `comanda-tiers-preview.html` | Comanda — pruebas de tiers de tamaño |
| `comanda-unificada-preview.html` | Comanda actual (formato vigente producido por `printKitchenCommandDirect`) |

Ver [`caracteristicas/comandas_cocina.md`](../caracteristicas/comandas_cocina.md) para el detalle del formato y sus reglas.

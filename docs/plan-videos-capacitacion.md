## � Permisos del Sistema (referencia para producción de videos)

Cada video se orienta al usuario que tiene el permiso necesario para acceder a esa funcionalidad.
El Administrador (dueño) tiene todos los permisos por defecto.

| Grupo | Permiso | Etiqueta UI | Quién lo tiene típicamente |
|-------|---------|-------------|---------------------------|
| **POS** | `pos_view` | Acceso al POS | Cajero, Mesero, Admin |
| | `pos_sell` | Finalizar Ventas | Cajero, Admin (mesero NO) |
| | `pos_open` | Abrir Turno | Cajero, Admin |
| | `pos_discount` | Aplicar Descuentos | Admin (configurable) |
| | `pos_cancel` | Anular Facturas | Admin (configurable) |
| | `pos_refund` | Devoluciones | Admin (configurable) |
| | `pos_close` | Cierre de Caja | Cajero, Admin |
| **Inventario** | `inv_view` | Ver Productos | Cajero, Admin |
| | `inv_create` | Crear/Editar Productos | Admin |
| | `inv_stock` | Ajustar Stock | Admin (configurable) |
| | `inv_purchase` | Registrar Gastos | Admin (configurable) |
| **Finanzas** | `clients_view` | Cuentas por Cobrar | Cajero, Admin |
| | `debts_view` | Cuentas por Pagar | Admin |
| **Admin** | `admin_users` | Gestionar Empleados | Admin |
| | `admin_reports` | Ver Reportes | Admin |
| | `admin_settings` | Configuración | Admin (dueño) |

> **Nota:** Los permisos son granulares e independientes del rol. Un "Cajero" es solo un preset
> de permisos; el dueño puede personalizar qué ve cada empleado individualmente.

## 💡 Notas de Producción

- **Plataforma de alojamiento**: Cloudinary (ya en uso, soporta thumbnails automáticos)
- **Formato**: MP4, resolución 1080p mínimo
- **Estilo**: Screencast con narración en español colombiano
- **Duración ideal por video**: 2-5 minutos (máximo 5 para mantener atención)
- **Cada video debe**:
  - Mostrar el flujo completo de inicio a fin
  - Usar datos de ejemplo realistas (tienda/minimercado)
  - Incluir subtítulos o texto en pantalla para pasos clave

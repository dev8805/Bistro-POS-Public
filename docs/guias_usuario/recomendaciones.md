# Recomendaciones para usar Bistro correctamente

> Guía para: Todos
> Módulo: Configuración inicial
> Tiempo estimado: 10 minutos

---

## ¿Para qué sirve?

Esta guía reúne las configuraciones recomendadas antes de empezar a usar Bistro: el navegador ideal, cómo instalar la app en tu dispositivo y cómo preparar WhatsApp en el computador para compartir comprobantes de venta. Si quieres saber cómo preparar el equipo para Bistro, cómo instalar la app en el celular o el computador, o cómo activar el envío de tiquetes y recibos por WhatsApp, aquí está todo.

---

## Antes de empezar

- Necesitas conexión a internet para las instalaciones iniciales.
- En computador: tener **Google Chrome** instalado y acceso a la **Microsoft Store**.
- En celular Android: usar **Chrome** para instalar. En iPhone: usar **Safari**.

---

## Paso a paso

### 1️⃣ Usar Google Chrome como navegador

Bistro está optimizado para **Google Chrome**. Otros navegadores pueden causar problemas con el escáner de cámara, la impresora térmica y la instalación como app.

```
Compatibilidad de navegadores
──────────────────────────────
✅  Google Chrome   (recomendado)
⚠️  Microsoft Edge  (parcial)
❌  Firefox          (sin impresora)
❌  Safari iPhone    (solo básico)
──────────────────────────────
```

> ⚠️ **Aviso:** Firefox y Safari no soportan la conexión con impresoras térmicas ni lectores USB. Usa **Chrome** para tener todas las funciones disponibles.

---

### 2️⃣ Instalar Bistro como app en computador

Instalar Bistro como app te da pantalla completa, acceso directo desde el escritorio y mejor rendimiento — sin las barras del navegador.

1. Abre **Google Chrome** y entra a Bistro.
2. Busca el ícono de instalación en la barra de direcciones:

```
┌────────────────────────────────────┐
│ 🔒 posbistro.online          ⊕  ⋮ │
└────────────────────────────────────┘
                               ▲
                        Ícono instalar
```

3. Haz clic en **⊕** o en **⋮** → **Instalar Bistro POS**:

```
┌─ Menú Chrome ──────────────────────┐
│  Nueva pestaña                     │
│  ────────────────────────────────  │
│  ✦  Instalar Bistro POS...         │
│  ────────────────────────────────  │
└────────────────────────────────────┘
```

4. Confirma en el diálogo:

```
┌─ Instalar aplicación ──────────────┐
│                                    │
│   🟡  Bistro POS                   │
│   posbistro.online                 │
│                                    │
│  ┌──────────┐  ┌─────────────────┐ │
│  │ Cancelar │  │    Instalar     │ │
│  └──────────┘  └─────────────────┘ │
└────────────────────────────────────┘
```

Bistro aparece como ventana independiente y queda en el escritorio y el menú Inicio.

---

### 3️⃣ Instalar Bistro como app en celular Android

1. Abre **Chrome** en tu Android y entra a Bistro.
2. Chrome muestra un banner en la parte inferior:

```
┌────────────────────────────────────┐
│  Añadir Bistro POS a inicio        │
│  posbistro.online                  │
│                     [ Instalar ]   │
└────────────────────────────────────┘
```

3. Si el banner no aparece, toca **⋮** arriba a la derecha:

```
┌─ Menú Chrome Android ──────────────┐
│  Nueva pestaña                     │
│  ────────────────────────────────  │
│  ✦  Añadir a pantalla de inicio    │
│  ────────────────────────────────  │
└────────────────────────────────────┘
```

4. Confirma el nombre y toca **Añadir**. El ícono de Bistro queda en tu pantalla de inicio.

> 💡 **Consejo:** La app instalada en Android funciona sin internet. Tus ventas se guardan aunque pierdas señal y se sincronizan cuando vuelvas a conectarte.

---

### 4️⃣ Instalar Bistro como app en iPhone (iOS)

En iPhone debes usar **Safari** para instalar — Chrome en iOS no permite instalación de apps web.

1. Abre **Safari** y entra a Bistro.
2. Toca el botón de compartir en la barra inferior:

```
┌────────────────────────────────────┐
│ ← posbistro.online           ↺  📤 │
└────────────────────────────────────┘
                                   ▲
                          Botón compartir
```

3. En el menú deslizable, toca **Agregar a pantalla de inicio**:

```
┌─ Safari — Compartir ───────────────┐
│  ...                               │
│  ┌──────────────────────────────┐  │
│  │ 📌 Agregar a pantalla inicio │  │
│  └──────────────────────────────┘  │
│  ...                               │
└────────────────────────────────────┘
```

4. Confirma el nombre y toca **Agregar**.

> ⚠️ **Aviso:** En iPhone la app tiene algunas limitaciones frente a Android. Para la mejor experiencia, se recomienda usar Bistro en un computador o dispositivo Android.

---

### 5️⃣ Instalar WhatsApp en computador desde Microsoft Store

Para compartir comprobantes de venta por WhatsApp al finalizar una venta, **debes tener WhatsApp instalado como app nativa**, descargada desde la **Microsoft Store**. La versión web no funciona con el sistema de compartir de Bistro.

> ⚠️ **Importante:** WhatsApp Web (`web.whatsapp.com`) no es compatible. Debes instalar la app de escritorio desde la **Microsoft Store**.

1. Abre la **Microsoft Store** desde el menú Inicio (busca "Microsoft Store"):

```
┌─ Menú Inicio → Buscar ─────────────┐
│  🔍 Microsoft Store                │
└────────────────────────────────────┘
```

2. Dentro de la tienda, busca **WhatsApp**:

```
┌─ Microsoft Store ──────────────────┐
│  🔍 [ whatsapp               ]     │
│                                    │
│  WhatsApp             ★ 4.3        │
│  WhatsApp Inc.                     │
│  ┌──────────────────────────────┐  │
│  │          Obtener             │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

3. Toca **Obtener** e instala la app.
4. Inicia sesión escaneando el código QR con el WhatsApp de tu celular.

> 💡 **Resultado:** Al finalizar una venta en Bistro y tocar **Compartir comprobante**, WhatsApp se abre directamente con el tiquete listo para enviar a tu cliente.

```
Flujo al finalizar una venta
────────────────────────────────
  Venta completada
       │
       ▼
  [ Compartir comprobante ]
       │
       ▼
  WhatsApp abre con
  el tiquete adjunto
       │
       ▼
  Seleccionas el contacto
  y envías ✅
────────────────────────────────
```

## Errores comunes

| Situación | Qué hacer |
|-----------|-----------|
| No aparece el ícono de instalar en Chrome | Recarga la página — puede tardar unos segundos en aparecer. |
| "Compartir comprobante" no abre WhatsApp | Verifica que WhatsApp esté instalado desde la **Microsoft Store**, no como web. |
| En iPhone no aparece "Agregar a pantalla de inicio" | Usa **Safari**, no Chrome ni otro navegador de iPhone. |
| Chrome en Android no muestra el banner de instalar | Ve al menú **⋮** → **Añadir a pantalla de inicio** manualmente. |
| La app instalada no carga al abrir | Verifica la conexión a internet — se requiere en el primer uso. |

---

## Preguntas frecuentes

**¿Por qué Bistro no funciona bien en Firefox o Edge?**
Bistro usa tecnologías del navegador para conectarse con impresoras térmicas y lectores USB. Solo **Google Chrome** tiene soporte completo para estas funciones. Firefox no las soporta; Edge funciona parcialmente.

**¿Qué diferencia hay entre usar Bistro en el navegador vs. instalarlo como app?**
Instalada como app, Bistro corre en su propia ventana sin barras del navegador, ocupa toda la pantalla, aparece en el escritorio o pantalla de inicio, y en Android funciona sin internet. La experiencia es considerablemente más fluida y profesional.

**¿Puedo usar WhatsApp Web en lugar de la app de escritorio?**
Sí funciona, pero al compartir un comprobante se abre una pestaña nueva en el navegador en lugar de abrir WhatsApp directamente. Esto interrumpe el flujo de la venta. Con la app instalada desde la **Microsoft Store**, WhatsApp se abre al instante sin salir de Bistro.

**¿La app en el celular es diferente a la del computador?**
Es la misma aplicación adaptada a cada pantalla. En celular se optimiza para uso táctil y cámara; en computador para teclado, pistola de barras y pantalla grande.

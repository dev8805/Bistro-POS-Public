# Cómo editar tu perfil en Bistro

> Guía para: Todos los usuarios
> Módulo: **Ajustes (Perfil)**
> Tiempo estimado: 5 minutos

---

## ¿Para qué sirve?

**Ajustes** es donde cada usuario edita sus datos personales dentro de Bistro: nombre, foto de perfil y teléfono de contacto. Cualquier usuario puede además vincular o cambiar su correo electrónico y su PIN de acceso. Los administradores también pueden cambiar el nombre del negocio, y el dueño puede, si lo necesita, eliminar toda la cuenta.

Si quieres cambiar tu foto, actualizar tu nombre, vincular o cambiar tu correo, cambiar tu PIN de acceso, editar el nombre del negocio (solo administradores) o eliminar el negocio de Bistro (solo el dueño), este es el lugar.

---

## Antes de empezar

- Puedes abrir **Ajustes** sin internet, pero **necesitas conexión para guardar** — sin red los cambios no se confirman.
- Los campos disponibles dependen de tu rol:

```
Cajero / Empleado   → Nombre, Teléfono, Avatar,
                      Correo, PIN de acceso
Administrador       → + Nombre del negocio
Dueño del negocio   → + Eliminar cuenta
```

---

## Paso a paso

Sigue los pasos según lo que quieras hacer. Todos los cambios se confirman con **Guardar Cambios** al final del formulario.

### 1️⃣ Abre tu perfil en móvil

En móvil, toca el avatar (o la inicial de tu nombre) en la esquina superior izquierda de la pantalla de inicio:

```
┌─ Inicio ───────────────────────┐
│  ╭───╮  Hola, Juan             │
│  │ J │← toca aquí             │
│  ╰───╯  Tienda Ejemplo         │
└────────────────────────────────┘
         ↓ se abre el panel
┌────────────────────────────────┐
│  ╭────╮  Juan Pérez            │
│  │ JP │  juan@correo.com       │
│  ╰────╯  CAJERO                │
├────────────────────────────────┤
│  👤  Mi Perfil          →      │
│  ⭐  Mi Suscripción     →      │
├────────────────────────────────┤
│  🚪  Cerrar Sesión             │
└────────────────────────────────┘
```

Toca **Mi Perfil** para abrir la pantalla de ajustes.

> 💡 Puedes cerrar el panel deslizando hacia abajo o tocando fuera de él.

### 2️⃣ Abre tu perfil en desktop

En desktop, toca el nombre del negocio (parte superior del menú lateral) para abrir el dropdown y elige **Mi Perfil**:

```
┌─ Sidebar ──────────────────────┐
│  Tienda Ejemplo  ∨  ← toca    │
│  juan@correo.com               │
├────────────────────────────────┤
│  👤 Mi Perfil                  │
│  ⭐ Suscripción  (si dueño)   │
│  ────────────────────────────  │
│  🚪 Cerrar Sesión              │
└────────────────────────────────┘
```

### 3️⃣ Cambia tu foto de perfil *(opcional)*

Toca el avatar circular en la parte superior de la pantalla. Se abre un menú con cuatro opciones:

```
    ╭──────╮
    │  JP  │  ← toca el avatar
    ╰──────╯
         ↓
┌──────────────────────────────┐
│  📁 Subir foto               │
│  📷 Tomar foto               │
│  📋 Pegar foto               │
│  ─────────────────────────── │
│  🗑 Eliminar foto            │
└──────────────────────────────┘
```

Todas las fotos pasan por un recortador cuadrado (1:1) antes de guardarse:

```
┌─ Recortar foto ──────────────┐
│  ┌────────────────────────┐  │
│  │                        │  │
│  │    [área de recorte]   │  │
│  │                        │  │
│  └────────────────────────┘  │
│  Arrastra para ajustar        │
│  [ Cancelar ]  [ Guardar ]   │
└──────────────────────────────┘
```

> 💡 **Eliminar foto** solo aparece si ya tienes una imagen cargada.

### 4️⃣ Edita tus datos personales

Los campos **Nombre Completo** y **Teléfono** están disponibles para todos los usuarios:

```
┌─ Ajustes ──────────────────────────┐
│                                    │
│  Nombre Completo                   │
│  ┌──────────────────────────────┐  │
│  │  Juan Pérez                  │  │
│  └──────────────────────────────┘  │
│                                    │
│  Teléfono                          │
│  ┌──────────────────────────────┐  │
│  │  300 123 4567   (Opcional)   │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

> 💡 El **Teléfono** es un dato de contacto — no es el número con el que inicias sesión en la app.

### 5️⃣ Edita el nombre del negocio *(solo Administradores)*

El campo **Negocio** solo aparece si tienes rol de Administrador. Es el nombre del negocio que aparece en los recibos.

```
┌─ Ajustes ──────────────────────────┐
│                                    │
│  Negocio                           │
│  Visible en los recibos.           │
│  ┌──────────────────────────────┐  │
│  │  Restaurante El Buen Sabor   │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

> ⚠️ **Aviso de bienvenida**: si el nombre sigue siendo "Mi Negocio" (el predeterminado al registrarse), el sistema muestra un aviso amarillo y enfoca automáticamente este campo:

```
╔══════════════════════════════════╗
║ 👋 ¡Bienvenido! Completa tu     ║
║ perfil. Ingresa el nombre de tu  ║
║ negocio y tus datos para         ║
║ comenzar.                        ║
╚══════════════════════════════════╝
       ↓ campo con foco automático
┌──────────────────────────────┐
│  Mi Negocio    ← cambiar     │
└──────────────────────────────┘
```

### 6️⃣ Edita el correo electrónico

El campo **Correo** está disponible para **todos los usuarios**. Si ya tienes un correo vinculado, aparece con un ✓ verde y un enlace **Cambiar**. Si aún no tienes ninguno, verás un campo para agregarlo.

```
┌─ Ajustes ──────────────────────────┐
│                                    │
│  Correo                            │
│  ✓ juan@restaurante.com   Cambiar  │
│    ← con correo vinculado          │
│  ┌──────────────────────────────┐  │
│  │  Escribe tu correo…          │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

Al escribir un correo nuevo, el botón **Guardar cambios** cambia a **Verificar**. Al guardar, el correo se actualiza **de inmediato** (no se cierra tu sesión) y Bistro muestra:

```
✅ Correo actualizado a juan@restaurante.com.
   Ya puedes usarlo para iniciar sesión.
```

> 💡 El correo nuevo queda listo al instante. No necesitas abrir ningún enlace ni volver a iniciar sesión.

> ⚠️ Si el correo ya pertenece a otra cuenta, Bistro lo rechaza: *"Este correo ya está registrado en otra cuenta. Usa uno diferente."*

### 🆔 Copia el ID de tu negocio *(opcional)*

En la parte superior del perfil, debajo de tu nombre y correo, aparece un chip gris con el código de tu negocio (`#` seguido del código). Tócalo para copiarlo al portapapeles:

```
╭────────────────────────────────╮
│  Juan Pérez          CAJERO     │
│  juan@correo.com                │
│  ┌──────────┐                   │
│  │ #A1B2C3 ⧉ │ ← toca para copiar│
│  └──────────┘                   │
╰────────────────────────────────╯
      ↓ al tocar
   #A1B2C3 ✓ Copiado
```

> 💡 Es el **ID de tu negocio** para soporte: cuando escribas al soporte humano, dícta este código para que el equipo encuentre tus conversaciones más rápido. Aparece para todos los roles, siempre que el negocio ya tenga un código asignado.

### 🔑 Cambia tu PIN de acceso *(opcional)*

En la parte superior del perfil, junto a tu nombre, está el botón **Cambiar PIN**. El PIN es el código de 4 dígitos con el que entras a Bistro usando tu teléfono.

```
╭──────────────────────────────────╮
│  Juan Pérez     [ 🔒 Cambiar PIN ]│
╰──────────────────────────────────╯
         ↓ toca "Cambiar PIN"
┌─ Cambiar PIN ────────────────────┐
│  Nuevo PIN       [ • • • • ]     │
│  Confirmar PIN   [ • • • • ]     │
│  [ Cancelar ]      [ Guardar ]   │
└──────────────────────────────────┘
```

Escribe el nuevo PIN (4 dígitos) y confírmalo. Toca **Guardar**. No pide tu PIN actual.

> 💡 Este cambio es independiente de **Guardar Cambios**: se aplica al toque, con su propio botón **Guardar**.

### 7️⃣ Guarda los cambios

Toca **Guardar Cambios** al pie del formulario:

```
┌──────────────────────────────────────┐
│  [ Cancelar ]  [ Guardar Cambios ]   │
└──────────────────────────────────────┘
```

> 💡 **El botón está gris** (desactivado) si no modificaste nada. Se activa en cuanto cambias al menos un campo o la foto.

Cómo fluye el guardado:

```
¿Hay conexión a internet?
  No → ✗ "Necesitas conexión a internet
           para guardar cambios…"
  Sí → continuar
         ↓
1. Guardar nombre, teléfono y avatar
         ↓
2. Si eres Admin → guardar nombre negocio
         ↓
3. Si cambiaste email → verificar que esté
   libre y actualizarlo de inmediato
         ↓
✅ "¡Perfil actualizado correctamente!"
   (o "Correo actualizado…" si cambiaste
    el correo)
```

> ⚠️ Si el paso 1 guarda bien pero el paso 2 falla, verás el error exacto de qué falló. El sistema no revierte lo que ya guardó.

### 8️⃣ Elimina la cuenta *(solo el Dueño)*

> 🔒 Esta sección solo aparece para el dueño registrado del negocio.

Al final de la pantalla aparece la tarjeta roja **"Zona peligrosa"** (borde rojo a la izquierda):

```
┌─ ⚠ Zona peligrosa ─────────────────┐
│ Eliminarás permanentemente tu      │
│ negocio, inventario, registros,    │
│ empleados y todo acceso. Esta      │
│ acción no se puede deshacer.       │
│              [ Eliminar cuenta ]   │
└────────────────────────────────────┘
```

Al tocar **Eliminar cuenta** se abre un modal de confirmación:

```
┌─ Eliminar cuenta ────────────────┐
│ ⚠  Esta acción no se puede       │
│    deshacer                      │
├──────────────────────────────────┤
│ Se eliminarán permanentemente:   │
│  • Tu negocio y configuración    │
│  • Productos e inventario        │
│  • Ventas y registros de caja    │
│  • Empleados y cuentas           │
├──────────────────────────────────┤
│ Escribe ELIMINAR para confirmar: │
│ ┌────────────────────────────┐   │
│ │  ELIMINAR                  │   │
│ └────────────────────────────┘   │
│  [ Cancelar ]  [ Eliminar todo ] │
└──────────────────────────────────┘
```

El botón **Eliminar todo** solo se activa con la palabra exacta `ELIMINAR` (mayúsculas). Al confirmar:

```
Confirmación recibida
        ↓
1. Borrar imágenes de productos
        ↓
2. Borrar logos del negocio
        ↓
3. Borrar avatares de empleados
        ↓
4. Eliminar todos los registros
        ↓
5. Cerrar sesión automáticamente
```

> ⚠️ **Esto es permanente.** Todos los datos del negocio, historial de ventas y accesos de empleados desaparecen de forma inmediata e irrecuperable.

## Errores comunes

Aquí están las situaciones más frecuentes y cómo resolverlas.

| Situación | Qué hacer |
|-----------|-----------|
| "Necesitas conexión a internet…" | Conéctate — los cambios de perfil no se guardan sin red |
| El botón "Guardar Cambios" está gris | Normal — solo se activa cuando modificas algo |
| "Este correo ya está registrado en otra cuenta" | Usa un correo distinto — ese ya lo tiene otra cuenta |
| Cambié el correo y no me pidió confirmar nada | Normal — el correo se actualiza al instante, sin enlace |
| El campo Negocio no aparece | Solo visible para Administradores |
| Veo un campo para escribir el correo en vez de mi email | Normal — significa que aún no tienes un correo vinculado |
| La foto no parece guardarse | La foto se sube al seleccionarla, pero el perfil se confirma al tocar **Guardar Cambios** |

## Preguntas frecuentes

Estas son las dudas más comunes al editar el perfil en Bistro.

### FAQ — ¿Qué campos puedo editar según mi rol?

Depende de tu rol dentro del negocio:

```
Cajero / Empleado
  ☑ Nombre Completo
  ☑ Teléfono (contacto)
  ☑ Foto de perfil
  ☑ Correo electrónico
  ☑ PIN de acceso
  ☐ Nombre del negocio
  ☐ Eliminar cuenta

Administrador (no dueño)
  ☑ Nombre Completo
  ☑ Teléfono (contacto)
  ☑ Foto de perfil
  ☑ Correo electrónico
  ☑ PIN de acceso
  ☑ Nombre del negocio
  ☐ Eliminar cuenta

Dueño del negocio
  ☑ Todo lo anterior
  ☑ Eliminar cuenta
```

### FAQ — ¿Cambiar mi teléfono aquí cambia el número con el que inicio sesión?

No. El campo **Teléfono** en Ajustes es solo un dato de contacto visible dentro de la app. El número de inicio de sesión está vinculado a tu cuenta de autenticación y no se puede cambiar desde esta pantalla.

```
Cambias "Teléfono" en Ajustes
         ↓
¿Cambia el número de inicio de sesión?
  Sí → ❌ No. Son campos distintos.
  ─────────────────────────────────
  El teléfono en Ajustes = contacto
  El número de sesión    = autenticación
  (no editable desde Ajustes)
```

### FAQ — ¿Cambiar el nombre del negocio cambia lo que aparece en los recibos?

Parcialmente. El campo **Negocio** en Ajustes edita el nombre interno del sistema.

```
¿Tienes "Nombre en facturas" configurado?
  Sí → el recibo usa ese nombre
  No → el recibo usa el nombre de Ajustes
       como respaldo
```

Verifica los dos lugares si quieres asegurarte de que el recibo muestre el nombre correcto.

### FAQ — ¿Puedo cambiar mi contraseña (PIN) desde aquí?

Sí. Usa el botón **Cambiar PIN** en la parte superior del perfil. El PIN es el código de 4 dígitos con el que entras a Bistro usando tu teléfono. También puedes entrar con un código por SMS o con Google. No se usa una contraseña larga tradicional.

### FAQ — ¿El cambio de correo necesita que confirme un enlace?

No. El correo se actualiza al instante cuando tocas **Verificar / Guardar cambios**, sin enlaces ni pasos extra.

```
Escribes un correo nuevo → tocas Verificar
         ↓
¿El correo ya lo usa otra cuenta?
  Sí → ❌ "Ya está registrado en otra cuenta"
  No → ✅ se actualiza de inmediato
         ↓
Tu sesión sigue abierta y ya puedes
iniciar sesión con el correo nuevo
```

### FAQ — ¿Puedo recuperar el negocio después de eliminar la cuenta?

No. La eliminación es permanente e inmediata. Si quieres pausar el uso de Bistro temporalmente, simplemente deja de iniciar sesión — no necesitas eliminar la cuenta.

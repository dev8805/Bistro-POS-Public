# Formato de MISSION.md

El archivo `MISSION.md` vive en `docs/aprendizaje/MISSION.md`.
Define la razón concreta por la cual estás aprendiendo el tema y evita que las lecciones se vuelvan teóricas o abstractas.

---

## Plantilla

```markdown
# Misión: [Tema a aprender — ej. React Hooks y Estado en Bistro]

## ¿Por qué lo estoy aprendiendo?
[1 a 3 oraciones explicando el objetivo concreto. Qué serás capaz de construir o modificar en Bistro una vez que domines este tema].

## Criterios de Éxito (Cómo sabemos que lo logramos)
- [ ] Ser capaz de crear un hook personalizado desde cero para sincronizar datos.
- [ ] Entender cuándo usar `useEffect` y cuándo evitarlo para no crear loops infinitos.
- [ ] Depurar errores de renderizado en `SellScreen` sin ayuda.

## Restricciones y Preferencias
- Explicaciones con analogías sencillas y paso a paso.
- Ejemplos usando TypeScript y TailwindCSS (el stack de Bistro).

## Fuera de Alcance (Por ahora)
- [Temas avanzados que se dejan para después para no saturar la mente].
```
